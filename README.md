# 🔎 Company Research Assistant

A simple company research app built with LangGraph, Groq, Alpha Vantage, NewsAPI, and Streamlit.
Enter a company name and the app collects information from different sources and combines it into
a short research report.

🏢 Company overview
💰 Financial performance
📰 Recent news
📋 Key takeaways

## Live Demo

[Try the Company Research Assistant](https://company-research-assistant5.streamlit.app/)

## Tech Stack

- Python
- LangGraph
- LangChain
- Groq
- Streamlit
- Alpha Vantage API
- NewsAPI
